M5 Outcome Designer

Design a value-share that survives scale

An M5 fee is never simply “a percent of value.” It’s a clamped — and ideally tiered — function:

\[\text{Fee} = \max\big(\text{Floor},\ \min(\text{Ceiling},\ \text{Value} \times \text{Share}\%)\big)\]

Set the floor, ceiling, and share below, then watch the fee curve. The lesson lands fast: a flat share looks fine at small value but becomes a renegotiation magnet at scale — a tiered (Lehman-style) schedule stays durable.

  "Caps the fee at this multiple of the floor. Guards against renegotiation risk if value scales a long way past what was priced for.")

Tiered (Lehman) schedule — edit the steps

What is “Lehman tiering”? It’s named after the classic Lehman Formula, the declining-rate fee scale investment banks have long used for M&A advisory success fees (the original 1960s Lehman Brothers rule of thumb was 5% of the first $1M, 4% of the next, 3% of the next, and so on down to 1%). The mechanism is simple: instead of one flat percentage applied to the whole pool of value, the value is split into bands, and each successive band is charged at a lower rate than the one before it.

Applied to outcome-based AI pricing, it solves the exact problem a flat share creates: a flat % feels fair on a modest deal, but multiply it across a huge value pool and the fee balloons into what looks like a windfall — inviting renegotiation, or worse, a reputation for opportunistic pricing. Tiering the rate downward as value climbs keeps the vendor’s take proportionate at every scale, so the deal that looked fair at signing still looks fair a year later when the customer’s usage has 10×’d. Below, the three bands (t1rate down through t3rate) default to a 4% / 2.5% / 1% schedule — edit them to see how the fee curve bends.

viewof t1rate = withDescription(Inputs.range([0.01, 0.06], {value: 0.04,  step: 0.005, label: "Rate on first band"}),
  "Highest of the three rates — charged on value up to the first band's cap below.")
viewof t1cap  = withDescription(Inputs.range([100000, 1000000], {value: 500000, step: 50000, label: "First band up to (£/mo)"}),
  "Value up to this point is charged at the first (highest) rate above.")
viewof t2rate = withDescription(Inputs.range([0.01, 0.05], {value: 0.025, step: 0.005, label: "Rate on second band"}),
  "Middle rate — charged on the slice of value between the first and second band caps.")
viewof t2cap  = withDescription(Inputs.range([1000000, 3000000], {value: 2000000, step: 100000, label: "Second band up to (£/mo)"}),
  "Value between the first cap and this point is charged at the second rate above.")
viewof t3rate = withDescription(Inputs.range([0.005, 0.03],{value: 0.01,  step: 0.005, label: "Rate above second band"}),
  "Lowest of the three rates — charged on any value above the second band's cap, keeping the fee proportionate at very large scale.")
chartMax = 5000000

floor   = m4base * floorPct
ceiling = ceilMult * floor

clamp = (x) => Math.max(floor, Math.min(ceiling, x))

flatRaw   = (v) => v * flatShare
tieredRaw = (v) => t1rate * Math.min(v, t1cap)
                 + t2rate * Math.max(0, Math.min(v, t2cap) - t1cap)
                 + t3rate * Math.max(0, v - t2cap)

flatFee   = (v) => clamp(flatRaw(v))
tieredFee = (v) => clamp(tieredRaw(v))

binding = (raw) => raw <= floor ? "floor binds" : raw >= ceiling ? "ceiling binds" : "share applies"

shareBand = ({
  "Cost takeout (labour replaced)":     "3–5%",
  "Cost avoidance (fraud, penalties)":  "2–4%",
  "Revenue uplift (attributed)":        "2–4%",
  "Risk reduction (liability avoided)": "2–5%"
})[valueType]

gbp  = (x) => "£" + Math.round(x).toLocaleString("en-GB")
gbpC = (x) => x >= 1e6 ? "£" + (x/1e6).toFixed(x >= 1e7 ? 0 : 2) + "M"
            : x >= 1e3 ? "£" + Math.round(x/1e3) + "k" : "£" + Math.round(x)
axisFmt = (s) => s >= 1e6 ? "£" + (s/1e6) + "M" : s >= 1e3 ? "£" + (s/1e3) + "k" : "£" + s
pct  = (x) => (100*x).toFixed(1) + "%"

curve = {
  const n = 240, a = [];
  for (let i = 0; i <= n; i++) {
    const v = chartMax * i / n;
    a.push({v, fee: flatFee(v), series: "Flat share"});
    if (useTiered) a.push({v, fee: tieredFee(v), series: "Tiered (Lehman)"});
  }
  return a;
}

effCurve = {
  const n = 240, a = [];
  for (let i = 1; i <= n; i++) {
    const v = chartMax * i / n;
    a.push({v, eff: 100 * flatFee(v) / v, series: "Flat share"});
    if (useTiered) a.push({v, eff: 100 * tieredFee(v) / v, series: "Tiered (Lehman)"});
  }
  return a;
}

palette = ({"Flat share": "#C0392B", "Tiered (Lehman)": "#4AA82D"})

opPoints = useTiered
  ? [{v: expValue, fee: flatFee(expValue), series: "Flat share"},
     {v: expValue, fee: tieredFee(expValue), series: "Tiered (Lehman)"}]
  : [{v: expValue, fee: flatFee(expValue), series: "Flat share"}]
html`<div style="font-size:.9em;color:#555;margin:-.3em 0 .4em;">
  Recommended share for <b>${valueType}</b>: <b>${shareBand}</b>.
  Floor = ${gbp(floor)}/mo · Ceiling = ${gbp(ceiling)}/mo.</div>`

At your expected value

{
  const ev = expValue;
  const card = (name, colour, fee, raw) => `
    <div style="flex:1;background:${colour};color:#fff;border-radius:10px;padding:.85em 1.1em;">
      <div style="font-size:.78em;text-transform:uppercase;letter-spacing:.05em;opacity:.9;">${name}</div>
      <div style="font-size:1.7em;font-weight:800;">${gbp(fee)}<span style="font-size:.5em;font-weight:600;"> / mo</span></div>
      <div style="font-size:.9em;margin-top:.3em;">
        ${binding(raw)} · effective ${pct(fee/ev)} · ${gbp(fee*12)}/yr
      </div>
    </div>`;
  const flat = card("Flat share", "#C0392B", flatFee(ev), flatRaw(ev));
  const tier = useTiered ? card("Tiered (Lehman)", "#4AA82D", tieredFee(ev), tieredRaw(ev)) : "";
  return html([`<div style="display:flex;gap:.8em;">${flat}${tier}</div>`]);
}
{
  const ev = expValue, ff = flatFee(ev), tf = tieredFee(ev), fr = flatRaw(ev);
  let level, msg;
  if (fr >= ceiling) {
    level = "warn";
    msg = `At ${gbpC(ev)} the flat share would blow through the ceiling — the cap is doing all the work, and the headline % will feel unfair to the customer. A tiered schedule lands more naturally.`;
  } else if (useTiered && ff > 1.25 * tf) {
    level = "warn";
    msg = `The flat fee (${gbpC(ff)}) is ${(ff/tf).toFixed(1)}× the tiered fee here — high renegotiation risk. At scale a flat % reads as a windfall; the tiered schedule defuses it.`;
  } else {
    level = "ok";
    msg = `At ${gbpC(ev)} the schedules are close and either is defensible — but the gap widens as value grows. Lock the tiered steps in now.`;
  }
  const c = level === "warn" ? "#E8830C" : "#4AA82D";
  return html`<div style="border-left:5px solid ${c};background:${c}14;padding:.7em 1em;border-radius:8px;font-size:.98em;">
    <b style="color:${c};">${level === "warn" ? "⚠ Renegotiation risk" : "✓ Balanced"}</b> — ${msg}</div>`;
}

Who keeps the value?

{
  const ev = expValue;
  const fee = useTiered ? tieredFee(ev) : flatFee(ev);
  const keep = Math.max(0, ev - fee);
  const fp = 100 * fee / ev, kp = 100 * keep / ev;
  return html`<div>
    <div style="display:flex;height:34px;border-radius:7px;overflow:hidden;font-size:.82em;color:#fff;font-weight:700;">
      <div style="width:${fp}%;background:#4AA82D;display:flex;align-items:center;justify-content:center;min-width:fit-content;padding:0 .4em;">
        Vendor ${pct(fee/ev)}</div>
      <div style="width:${kp}%;background:#0073E6;display:flex;align-items:center;justify-content:center;padding:0 .4em;">
        Customer keeps ${pct(keep/ev)}</div>
    </div>
    <div style="font-size:.9em;color:#555;margin-top:.4em;">
      Vendor captures <b>${gbp(fee)}/mo</b>; the customer retains <b>${gbp(keep)}/mo</b> of the value created.
      Growing the pool beats grabbing a bigger slice — 3% of £10M beats 15% of £1M.</div>
  </div>`;
}

Effective share — why flat doesn’t scale

Plot.plot({
  marginLeft: 50, marginBottom: 40, height: 300,
  x: {label: "Monthly value delivered →", tickFormat: axisFmt, grid: true},
  y: {label: "↑ effective share (fee ÷ value)", tickFormat: d => d + "%", grid: true,
      domain: [0, Math.max(flatShare, t1rate) * 100 * 1.25]},
  color: {legend: true, domain: Object.keys(palette), range: Object.values(palette)},
  marks: [
    Plot.line(effCurve, {x: "v", y: "eff", stroke: "series", strokeWidth: 2.5}),
    Plot.ruleX([expValue], {stroke: "#bbb", strokeDasharray: "2 2"}),
    Plot.ruleY([0])
  ]
})

The flat line stays constant until the ceiling clips it, then decays. The tiered line steps down smoothly — capturing more where Vendor contribution is proportionally highest (low-to-mid value) and compressing where the customer’s own operational context dominates. That declining curve is exactly what makes a tiered schedule feel fair, and survive renewal.
