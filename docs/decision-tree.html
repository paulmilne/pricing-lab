Model Selector

Answer a few questions, get a recommended pricing model

This walks the same decision tree as the CoE Model Selection Guide. Click your way through — each answer reveals the next question, and your recommendation appears at the end. Click any crumb in the trail to jump back and explore a different branch.

Start with the question that organises everything: who actually operates the AI, and who carries the risk if it goes wrong?

  const s = dt_state;                        // reactive dependency — re-runs on each click
  const wrap = html`<div></div>`;

  // ---- breadcrumb trail ----
  const bc = html`<div style="margin-bottom:.7em;"></div>`;
  const start = html`<span class="dt-crumb">↻ Start over</span>`;
  start.addEventListener("click", () => { mutable dt_state = {current:"start", path:[], risk:s.risk}; });
  bc.append(start);
  s.path.forEach((p, i) => {
    const cr = html`<span class="dt-crumb">${p.title}</span>`;
    cr.addEventListener("click", () => { mutable dt_state = {current:p.node, path:s.path.slice(0,i), risk:s.risk}; });
    bc.append(cr);
  });
  wrap.append(bc);

  const node = TREE[s.current];

  if (node.q) {
    wrap.append(html`<div class="dt-q">${node.q}</div>`);
    node.opts.forEach(opt => {
      const c = html`<div class="dt-card">
        <div class="dt-ico">${opt.icon || ""}</div>
        <div><div class="dt-t">${opt.title}</div><div class="dt-s">${opt.sub || ""}</div></div>
      </div>`;
      c.addEventListener("click", () => {
        mutable dt_state = {
          current: opt.next,
          path: [...s.path, {node: s.current, title: opt.title}],
          risk: s.risk
        };
      });
      wrap.append(c);
    });

  } else if (node.result) {
    const r = node.result;
    const panel = html`<div></div>`;
    panel.style.cssText = "border-left:7px solid "+r.color+";background:#f8f9fb;padding:1.1em 1.3em;border-radius:9px;";

    const tierEl = html`<div>${r.tier}</div>`;
    tierEl.style.cssText = "font-size:.8em;text-transform:uppercase;letter-spacing:.06em;font-weight:700;color:"+r.color+";";
    const modelEl = html`<div>${r.model}</div>`;
    modelEl.style.cssText = "font-size:1.85em;font-weight:800;margin:.12em 0 .55em;";
    panel.append(tierEl, modelEl);

    // promoted gate / clause boxes
    (r.badges || []).forEach(bd => {
      const box = html`<div></div>`;
      box.style.cssText = "display:flex;gap:.55em;align-items:flex-start;background:"+bd.color+"14;"
        + "border:1px solid "+bd.color+"55;border-left:5px solid "+bd.color+";border-radius:7px;"
        + "padding:.6em .8em;margin:.15em 0 .6em;";
      const ic = html`<span>${bd.icon}</span>`;
      ic.style.cssText = "font-size:1.15em;line-height:1.3;";
      const tx = html`<span>${bd.text}</span>`;
      tx.style.cssText = "font-size:.88em;font-weight:600;color:#2a2a2a;line-height:1.35;";
      box.append(ic, tx);
      panel.append(box);
    });

    const rq = html`<div style="margin:.4em 0;"><strong>Risk level:</strong> </div>`;
    RISK.forEach(rb => {
      const b = html`<span class="risk-btn">${rb.label}</span>`;
      if (s.risk === rb.key) { b.style.background = rb.color; b.style.color = "#fff"; b.style.borderColor = "transparent"; }
      b.addEventListener("click", () => { mutable dt_state = Object.assign({}, s, {risk: rb.key}); });
      rq.append(b);
    });
    panel.append(rq);

    const appr = RISK.find(x => x.key === s.risk).approval;
    panel.append(html`<div style="margin:.35em 0 .7em;"><strong>Approval path:</strong> ${appr}</div>`);

    const ul = html`<ul style="margin:0;padding-left:1.2em;line-height:1.55;"></ul>`;
    r.notes.forEach(n => ul.append(html`<li>${n}</li>`));
    panel.append(ul);

    panel.append(html`<div style="margin-top:.95em;font-size:.95em;">→ Now price it in the <a href="comparator.html">Five-Model Comparator</a>.</div>`);
    wrap.append(panel);
  }

  return wrap;
}
This is guidance, not gospel

The tree encodes the default path for each situation. Real deals have nuance — a strong attribution story can pull a borderline case up a tier; a nervous customer can pull it down. Use the recommendation as the starting position for the commercial conversation, then apply the full CoE pre-qualification (P1–P8) before committing to M5.
